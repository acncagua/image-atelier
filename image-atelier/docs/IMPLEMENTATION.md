# 実装メモ

確認日: 2026-09-11

## 専用の環境で既存アプリと分離

作業フォルダーは既存コードのないGitリポジトリだった。適用される親ディレクトリーのAGENTS.mdは見つからなかった。Python 3.12.10、Node.js 22.20.0を確認し、image-atelier配下に専用仮想環境を作成した。APIキーは未設定。利用者の指定に従い、実API試験は行わない。

画像処理はPillow、バックエンドはFastAPI、永続化はSQLite、画面はReactとViteを採用。SD環境と分離し、ビルドした画面を同じローカルサーバーから配信する。既存アプリが候補ポートを使用していたため、専用ポート18791を採用した。接続先は127.0.0.1のみ。

キーはconfig.local.jsonのopenai_api_keyを優先し、空欄の場合は環境変数からバックエンドでのみ参照する。設定ファイルはGit対象外。Host/Origin検証と起動ごとのトークンで別サイトからの操作を防ぐ。例外本文や認証ヘッダーはログに出さない。画像・履歴・生成物はGit対象外。Windowsでは同じdataに対する二重起動をファイルロックで拒否する。

## API能力は capabilities.json に集約

[画像生成ガイド](https://developers.openai.com/api/docs/guides/image-generation)と、[Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)、[Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)の公式モデルページを確認した。両モデルの品質候補はlow、medium、high、xhigh、max、auto。カスタム寸法の制約は設定ファイルに保存し、送信前に検証する。

Images APIのgenerations/editsを使用し、別のテキストモデルは呼ばない。編集対象、役割付き資料の順でmultipartのimage[]に送る。部分修正では最初の画像に対応するPNGマスクを付け、選択範囲のアルファを0とする。input_fidelityは送信しない。モデル・品質・寸法の自動置換はない。

初期版はPNG・1回1枚・入力8枚まで・アップロード1枚20MBまでに制限した。この枚数・容量はアプリ側の制限で、APIの上限を保証する値ではない。変換後PNGも50MB未満を検証する。候補モデルのアカウント対応、最大入力枚数、容量境界の実API受理は未検証。

公式モデルページに記載された非キャッシュ入力と画像出力のトークン単価を設定ファイルに記録した。十分な非キャッシュ内訳がある応答だけ概算し、キャッシュ内訳が不明なら計算しない。予約額は概算と区別し、完了と結果不明では解放しない。計算結果は請求確定額ではない。

## 元データを残し、ジョブを再送しない

入力の原データをoriginal.bin、向きと色を整えた作業画像をimage.pngとして保存する。API生出力も元のバイト列を保持する。履歴には資料ID、ハッシュ、役割、人物の説明、親画像、送信指示文、モデル、品質、要求・実寸法、使用量、リクエストID、経過時間を保存する。

合成前に寸法一致を必須とし、マスクに内側へのぼかしを掛ける。塗っていない画素は作業用元画像からそのまま保持する。内容の位置ずれを自動判定する機能はない。

SQLiteへジョブを記録してから、1本のワーカーで順に処理する。ジョブIDと実行中の同条件照合で重複送信を防ぐ。再起動時は送信中を結果不明、待機中を待機取消にする。自動再試行回数は0回。APIのエラー本文を保存せず、HTTP分類のみ表示する。予約額を超える実費や他ツールからの支出までは制限しない。

## 見本を基に操作に必要な項目を追加

Image Genの組み込みツールで空の画面を設計した。プロンプトの要旨は「Image Atelier、日本語のローカル画像編集、白いパネル、灰色のキャンバス、青緑の実行ボタン、左の資料・指示、左右比較、下の履歴。作品画像なし」。見本はconcept.png。

白・薄灰・青緑の配色、337pxの左パネル、左右比較、細い境界線、抑えた角丸を採用した。要件に必要な寸法入力、比率保持、マスク、プリセット、保存、説明を追加。見本のGIF表示とOSのウィンドウ操作は採用せず、履歴とジョブは1つの表に統合した。画像を画面そのものとして貼り付けてはいない。
